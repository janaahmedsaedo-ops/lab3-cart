# Lab 3 - Shopping Cart Counter
 
A small interactive page built with **HTML**, **CSS** and **JavaScript** for the CSE343 Web Development course.
 
## Features
 
- **Show Quantity** displays the current number of items in the cart
- **Add to Cart** adds 1 item
- **+2** adds 2 items
- **+3** adds 3 items
- **Reset Cart** sets the quantity back to 0
## Files
 
| File | Description |
|---|---|
| `lab3.html` | The page structure (HTML) |
| `lab3.css` | The page styling (CSS), linked from the HTML file |
| `lab3.js` | The cart logic (JavaScript), linked from the HTML file |
 
## How to Run
 
1. Download or clone this repository.
2. Keep the three files in the same folder.
3. Open `lab3.html` in any web browser.
4. Click the buttons to change the quantity, then click **Show Quantity** to display it.
